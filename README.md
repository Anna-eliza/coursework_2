# Coursework 2: Интеграция с API самолетов

Программа собирает данные о самолетах в воздушном пространстве выбранной страны, используя API nominatim.openstreetmap.org (координаты) и opensky-network.org (данные о самолетах).

## Возможности

- Получение координат страны по названию.
- Получение информации о самолетах в воздушном пространстве страны.
- Сохранение данных в JSON-файл.
- Вывод топа N самолетов по высоте (сортировка по убыванию).
- Фильтрация по стране регистрации.
- Обработка ошибок сети и некорректного ввода.

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/Anna-eliza/coursework_2.git
cd coursework_2
poetry install
```

## Запуск

Запустите основной скрипт:

```bash
poetry run python src/main.py
```

## Тестирование

Запустите тесты с подсчетом покрытия:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```
